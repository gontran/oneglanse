## Avertissement

Les donnees affichees dans ce dashboard sont des **donnees de demonstration** entierement fictives. Aucun audit reel n'a ete effectue. Les reponses des surfaces IA (ChatGPT, Gemini, Perplexity, Claude, Google AI Overview) sont simulees a des fins de demonstration.
